# 单调累计脱谱证据与多尺度差分定位方案

## 一、文档状态

- 状态：已否决，仅保留为历史诊断记录，不得继续作为训练标签、候选锚点主方案或真实性依据。
- 后继方案：`SMALL_TRANSFORMER_CHANGE_POINT_OFFBOOK_PLAN.md`。
- 日期：2026-08-11。
- 目标：评估能否只使用程序、经典统计拟合、预先选定的自变量和现有数据，构造一条单调累计证据曲线 `d`，再通过从粗到细的一阶差分 `v`、二阶差分 `a` 定位脱谱点。
- 边界：本方案不要求训练神经网络，也不依赖 TCN。现行人工脱谱登记规则仍以根目录 `METHOD.md` 为准；在本方案通过独立验证以前，脚本输出只能称为“候选脱谱点”，不能改写人工锚点。

## 二、核心假设

脱谱不是彼此独立的逐节点分类问题，而是一个只发生一次的序列变化事件。

对目标选手的第 `i` 次决策，定义：

```text
d(i) = 截至当前节点累计了多少脱谱证据
```

随着棋局推进，“脱谱已经发生过”的累计证据原则上不应减少，因此希望：

```text
d(i) >= d(i-1)
```

理想曲线形态为：

```text
谱内阶段：d处于低位并缓慢增长
接近脱谱：d的增长开始加速
脱谱附近：d的增长速度达到高位
脱谱以后：d保持高位或继续缓慢增长
```

本方案不寻找整局最大的 `d`，而是寻找 `d` 从正常缓慢增长转为明显快速增长的最早可信位置。

## 三、为什么累计不必丢失局部信息

先为每个节点计算非负的新增证据 `h(i)`，再累计得到 `d`：

```text
h(i) >= 0
d(i) = d(i-1) + h(i)
```

于是：

```text
v(i) = d(i) - d(i-1) = h(i)
a(i) = v(i) - v(i-1)
```

三个量分别表示：

- `d`：截至当前的累计脱谱证据；
- `v`：`d` 的一阶差分，表示当前节点新增加了多少脱谱证据；
- `a`：`d` 的二阶差分，也是 `v` 的一阶差分，表示新增证据相对上一节点是在加速、稳定还是减速。

这里的单调性必须来自“累计非负新增证据”的结构，不能通过对普通分数取历史最大值事后强行制造。取历史最大值会丢失孤立突变、持续变化和恢复之间的区别。

初期建议让 `d` 保持为无上限的累计证据指数，不立即解释为 0 到 1 的概率。概率饱和会压低后段差分，且未经校准的分数本来也不具备概率含义。验证有效后可以另行做概率校准。

## 四、候选自变量

自变量由人预先确定，程序只负责标准化、拟合少量函数形状和系数。候选变量应保留原始分量，便于解释最终 `d` 的来源。

### 4.1 时间信息

- 当前目标选手实际思考时间；
- 目标选手最近若干次决策的思考时间水平和变化；
- 对手上一手以及两次目标决策之间累计的思考时间；
- 当前双方剩余时间与时间控制；
- 当前用时相对同一选手、相近阶段正常用时的偏离；
- 当前用时相对同类棋盘状态正常用时的偏离。

对手时间不能简单视为无关时间。目标选手可能在对手计时期间继续思考，因此需要同时保留自己用时、对手用时以及二者的组合项，而不是只计算自己的单点长考。

### 4.2 棋谱与阶段信息

- 全局实际落子 `ply`；
- 目标选手自己的第几次决策；
- 当前完整棋盘在历史棋谱中的出现次数或比例；
- 当前选手个人 Frequency Book 的父节点次数、子节点次数和父子比例；
- `historical_choice`、`new_player_choice`、`unseen_parent` 等历史状态。

`ply` 主要用于描述正常基线和阶段，不应单独主导新增证据。否则公式可能只学到“棋局越往后越可能离开开局”，并总在平均开局长度附近报点。

### 4.3 局面与选择信息

- 落子前棋盘复杂度；
- 合法着法数量；
- 候选着法接近程度；
- 当前着手子损及其邻域变化；
- 其他已经在仓库中稳定、可复现的局面特征。

这些变量用于区分“正常的复杂局面长考”和“从熟悉路线进入现场思考的变化”。任何需要落子后或未来节点才能得到的变量必须明确标记为离线分析信息，不能把对应算法宣传为实时检测。

## 五、11200 条棋谱与人工标记的不同作用

仅有自变量和 11200 条棋谱，不能唯一确定一条有“脱谱”语义的公式。程序还必须得到明确的拟合目标；否则 `d=ply`、`d=累计用时` 等大量单调公式都满足形式要求，却未必能定位脱谱。

### 5.1 11200 条棋谱

主要用于建立稳定的正常参照：

- 不同时间控制下的用时分布；
- 不同 `ply` 或目标决策序号下的正常变化；
- 双方时间组合的正常范围；
- 棋盘、历史频率、局面复杂度等变量的总体分布；
- 标准化参数以及正常波动阈值。

这些棋谱有真实时间标签，因此可以支持时间规律拟合，但不能自行赋予“脱谱”语义。只用这些数据时，算法严格识别的是“统计状态转折”或“时间状态转折”。

### 5.2 现有 Agent 人工标记

人工 `offbook` 锚点和 `no_offbook` 对局用于：

- 判断统计转折是否与现行脱谱定义一致；
- 拟合少量公式系数和检测阈值；
- 选择“加速开始、转折中心或转折结束”中的哪一个最接近人工锚点；
- 评估 `no_offbook` 误报率和跨棋手泛化。

同一批人工标记不能同时用于参数拟合和最终效果证明。建议按棋手做留一交叉验证：使用其余棋手拟合公式和阈值，只在完全留出的棋手上评价，再轮换所有棋手。

## 六、推荐的公式结构

初版不追求任意复杂的“高级公式”，而使用可审计的低维非线性结构：

```text
节点原始证据 s(i)
  = 常数项
  + 自己用时函数
  + 对手用时函数
  + 棋谱罕见度函数
  + ply/阶段基线函数
  + 局面复杂度函数
  + 子损或选择信息函数
  + 少量预先指定的交互项
```

每个单变量函数可以采用分段线性曲线或低自由度样条。程序使用约束最小二乘、坐标搜索或其他确定性的数值优化方法拟合系数；不需要神经网络。

先扣除正常基线，再只累计超过正常波动的部分：

```text
h(i) = max(0, s(i) - normal_baseline(i) - threshold)
d(i) = d(i-1) + h(i)
```

这样正常节点对 `d` 的贡献应接近零，避免小噪声在长棋局中无限累积。所有变量都必须先转换到可比较尺度；具体使用均值/标准差、稳健中心/尺度还是经验分位数，应根据 11200 局的分布诊断后固定，不能在单局内临时选择。

### 6.1 拟合目标

程序拟合公式参数时，应直接优化最终任务，而不是只追求公式对某个单一变量的拟合度。

对有人工锚点 `k` 的训练局，希望：

```text
k以前：新增证据较低，不应提前产生更强候选点
k附近：v明显增大，或出现持续为正的a
k以后：累计证据形成清晰的前后水平差
```

对 `no_offbook` 训练局，希望：

```text
允许d缓慢变化
但整局不能产生超过局级阈值的可信转折
```

优化目标至少同时包含：锚点附近奖励、锚点前误报惩罚、`no_offbook` 误报惩罚和公式复杂度惩罚。权重与阈值必须只在训练折中确定。

## 七、一阶差分 v 与二阶差分 a 的判读

### 7.1 一阶差分 v

```text
v较小：当前新增证据少
v持续较高：脱谱证据持续进入
v突然很高：孤立突变或突然脱谱候选
```

因为 `d` 单调，`v` 不会为负；重点是其大小、持续时间和相对正常基线的偏离。

### 7.2 二阶差分 a

```text
a为正：新增证据正在加速
a接近零：新增证据速度大体不变
a为负：新增证据仍可能为正，但增长已经减速
```

理想的加速型转折通常表现为：

```text
低v
→ v上升且a为正
→ v达到高位
→ a转负
```

如果人工定义强调“首次从熟悉路线进入现场思考”，最终点应优先选择最早的持续加速起点，而不是 `d` 最大点，也不一定是 `v` 最大点。

### 7.3 不能只保留一种形态

检测器至少需要覆盖：

1. 加速型：`v` 上升，`a` 持续为正；
2. 渐变型：`v` 连续较高，`a` 接近零；
3. 孤立突变型：`v` 单点很高，`a` 先正后负。

只要求 `a` 突然上升会漏掉稳定渐变；只要求变化持续又会漏掉可能有意义的孤立长考。

## 八、从粗到细的多尺度定位

多尺度的目的，是把“稳定发现大致转折区间”和“精确定位具体节点”分开完成。

建议使用重叠窗口，而不是互不重叠的固定分段。固定分段可能让真正边界落在两个窗口之间并被稀释。

初始候选尺度可以是目标选手决策数：

```text
8个决策窗口：扫描整局，寻找异常增长区间
4个决策窗口：在候选区间内缩小范围
2个决策窗口：确认转折发生在哪一小段
1个决策节点：确定最终候选锚点
```

每个尺度至少计算：

- 窗口前后的 `d` 水平差；
- 窗口内平均 `v`；
- `v` 相对前一窗口的变化，即粗尺度 `a`；
- 高新增证据是否持续；
- 候选区间之后是否形成新的较高水平。

推荐定位流程：

1. 在最大尺度找出具有明显前后水平差或持续加速的少数候选区间；
2. 逐级减小窗口，只在候选区间及其邻域继续搜索；
3. 在最细尺度区分加速型、渐变型和孤立突变型；
4. 选择最早满足完整确认条件的节点，而不是全局最高分节点；
5. 如果整局最高候选仍未超过按正常棋局校准的局级阈值，输出 `no_offbook`。

## 九、阈值必须按整局校准

不能直接把节点级第 95 百分位当作正式阈值。一局包含多个目标决策，即使每个正常节点只有 5% 误报率，整局至少出现一次误报的概率也会很高。

应在正常或 `no_offbook` 参照局中，对每局只保留“该局最大的候选分数”，再根据这些整局最大值选择阈值。这样阈值控制的是整局误报率，而不是单节点误报率。

不同时间控制、对局长度或数据范围是否需要分层阈值，必须通过预先规定的诊断决定，不能看到测试结果后临时调整。

## 十、验证设计

### 10.1 当前基线

现有单一 CNN+TCN 时间头与人工锚点评估提供了可复现基线：

- 145 个有锚点的选手－对局和 35 个 `no_offbook` 对局；
- 84.8% 的人工锚点实际用时高于模型预期；
- 人工锚点是该局最大正残差节点的比例为 20.0%；
- 最大残差位于人工锚点前后 1/2 个目标决策内的比例为 23.4%/30.3%；
- 节点级对数残差 ROC-AUC 为 0.772。

这些结果说明时间信号存在，但单点最大残差不足以稳定定位首次边界。新方案必须与该基线直接比较，而不能只展示个别成功案例。

### 10.2 必做消融

按以下顺序逐项增加机制：

1. 只使用单点实际用时；
2. 使用多参数节点原始证据；
3. 累计成单调 `d`，只使用一阶差分 `v`；
4. 增加二阶差分 `a`；
5. 增加多尺度粗到细定位；
6. 增加对手时间；
7. 增加棋盘、历史频率和局面信息；
8. 增加渐变型和孤立突变型通道。

这样才能判断提升来自综合公式、差分、多尺度，还是某个单独变量。

### 10.3 主要指标

- 精确命中人工锚点；
- 命中人工锚点前后 1 个目标决策；
- 命中人工锚点前后 2 个目标决策；
- 相对人工锚点的提前量或延迟量；
- `no_offbook` 对局的特异度和误报率；
- 每局候选点数量；
- 每位棋手的单独结果；
- 按棋手留一验证的汇总和整局 bootstrap 区间。

必须同时报告命中率和 `no_offbook` 特异度。通过降低阈值让每局都报点，不能视为有效提升。

## 十一、主要失败模式与控制

### 11.1 只学到棋局阶段

表现：候选点集中在固定 `ply`，与时间或其他证据关系弱。

控制：把 `ply` 主要放入正常基线；报告去掉 `ply` 后的消融；检查不同棋手、不同开局长度下的候选位置。

### 11.2 长棋局必然累计过阈值

表现：对局越长越容易报脱谱。

控制：只累计超过正常基线和噪声阈值的新增证据；按整局最大候选分数校准；分长度报告误报率。

### 11.3 把复杂局面长考等同于脱谱

表现：战术复杂节点无论是否存在前后状态变化都被选中。

控制：加入局面复杂度和预期用时参照；同时检查转折前后水平、持续性和对手时间，不只看当前用时。

### 11.4 对人工标记过拟合

表现：训练棋手命中率很高，留出棋手明显下降。

控制：限制公式自由度和交互项数量；按棋手留一拟合；任何最终指标只来自留出预测。

### 11.5 拟合与评估口径循环

表现：使用全部人工锚点调好公式后，又在同一批锚点上宣称成功。

控制：预先冻结数据划分、公式族、阈值选择和主指标；保留完全未参与拟合的测试结果。

## 十二、与其他候选方法的定位

当前建议顺序：

1. 单调累计证据 `d` 加多尺度一阶差分 `v`、二阶差分 `a`：主方案；
2. 马氏距离：多参数静态异常基线；
3. 现有时间预测残差：独立时间基线，也可作为一个候选自变量；
4. 马尔科夫或 HMM：只有在候选状态频繁抖动时，作为后处理研究；
5. 复杂机器学习脱谱分类器：在获得更多独立人工标签后再考虑。

马氏距离擅长发现某节点的联合异常，但不能直接回答“第一次状态转折在哪里”。马尔科夫模型擅长整理状态序列，但不能自行赋予隐藏状态以脱谱语义。当前方案直接围绕首次变化边界建模，因此与任务目标更一致。

## 十三、推荐实施顺序

### 阶段 A：冻结研究口径

1. 明确每个候选自变量的定义、可用时点和方向；
2. 明确目标选手决策序号与全局实际落子 `ply` 的映射；
3. 冻结人工锚点、`no_offbook` 和按棋手留一划分；
4. 冻结主指标和局级误报口径。

### 阶段 B：建立正常基线

1. 使用 11200 局计算变量分布和标准化参数；
2. 检查时间控制、`ply`、对局长度和棋手差异；
3. 固定正常基线和新增证据阈值的候选形式。

### 阶段 C：低自由度原型

1. 先只使用时间、对手时间、`ply` 基线和历史频率；
2. 用约束优化拟合少量系数；
3. 生成 `h`、`d`、一阶差分 `v` 和二阶差分 `a`；
4. 实现 8/4/2/1 重叠窗口的粗到细定位；
5. 完成按棋手留一验证。

### 阶段 D：逐项扩展

只有原型在留出棋手上优于时间残差基线时，才逐项加入棋盘复杂度、子损、更多非线性项和交互项。每次扩展都必须保留前一版本和完整消融结果。

## 十四、最终评价

该方案最有价值的部分，是把脱谱重新表述为：

```text
多参数产生节点新增证据
→ 新增证据累计成单调曲线
→ 曲线的首次结构性转折对应候选脱谱边界
```

它比单点异常分数更能表达前后连续性，比静态马氏距离更接近“首次边界”，又比无监督马尔科夫模型更容易赋予明确语义。其主要不确定性不在一阶差分 `v`、二阶差分 `a` 是否可计算，而在拟合出的 `d` 是否真正区别了脱谱、棋局阶段、局面复杂度和时间压力。

因此，该方案应作为当前最高优先级的算法研究主线，但必须通过按棋手留一、整局阈值和逐项消融证明其有效性。在验证完成前，它是候选脱谱检测器，不是人工脱谱事实的替代品。
